# Untl

A small timer for the macOS menu bar. Type what you want in plain words, hit return, and Untl counts down to it.

```
25m Work + 5m Break      15m x4      stopwatch
```

## Download

Get the latest `Untl-<version>.dmg` from the [Releases](../../releases/latest) page, open it and drag **Untl** onto **Applications**.

- Requires macOS 26 or later
- Signed and notarized by Apple
- Free to use
- Untl checks this page for updates and can install them from inside the app (the update is verified with a signature)

## Feedback
